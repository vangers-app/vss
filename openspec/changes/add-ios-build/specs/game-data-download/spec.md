# Spec Delta

## Purpose

Даёт приложению получить данные оригинальной игры по сети, когда локальная установка не найдена: нужно для iOS, где данные нельзя подложить вручную, и для desktop без Steam/GOG-копии.

## ADDED Requirements

### Requirement: Предложение скачать данные
Если при запуске Tauri-сборки (desktop или iOS) данные игры не найдены, экран «Game data not found» SHALL предлагать кнопку скачивания данных рядом со ссылками на Steam и GOG. URL источника зашит в приложение; пользователь его не вводит. На мобильных платформах кнопка Exit MUST NOT показываться.

#### Scenario: Первый запуск на iOS
- **WHEN** приложение запущено на iOS и в хранилище приложения нет папки с данными
- **THEN** показан экран «Game data not found» с кнопкой «Download game data», без кнопки Exit

#### Scenario: Desktop без Steam-копии
- **WHEN** приложение запущено на Linux/Windows/macOS и ни Steam-путь, ни хранилище приложения не содержат данных
- **THEN** показан тот же экран с кнопкой «Download game data» и кнопкой Exit

#### Scenario: Android
- **WHEN** приложение запущено на Android
- **THEN** данные распаковываются из бандла, как раньше; экран скачивания не показывается

### Requirement: Скачивание с прогрессом и отменой
Скачивание SHALL показывать прогресс (загружено / всего, если размер известен) и фазу («Downloading», «Extracting»). Пользователь SHALL иметь возможность отменить скачивание в любой момент; после отмены временные файлы MUST быть удалены, а экран возвращается к состоянию «Game data not found».

#### Scenario: Прогресс
- **WHEN** пользователь нажал «Download game data» и сервер отдаёт `Content-Length`
- **THEN** виден процент и объём загруженного, после загрузки — фаза распаковки

#### Scenario: Отмена
- **WHEN** пользователь нажимает Cancel во время загрузки или распаковки
- **THEN** скачивание прекращается, временный архив и временная папка удалены, снова показан экран «Game data not found»

### Requirement: Атомарная установка данных
Данные SHALL становиться видимыми приложению только целиком: распаковка идёт во временную папку, которая переименовывается в итоговую после успешного завершения. При ошибке сети или распаковки SHALL показываться сообщение с кнопками Retry и Close, итоговая папка MUST NOT остаться частично заполненной.

#### Scenario: Обрыв сети
- **WHEN** соединение обрывается посреди загрузки
- **THEN** показано сообщение об ошибке с Retry; папка данных не создана

#### Scenario: Успех
- **WHEN** загрузка и распаковка завершились
- **THEN** показано сообщение об успехе с кнопкой Restart; после перезапуска приложение находит данные и запускает игру без повторного скачивания

### Requirement: Повторные запуски
После успешной установки приложение SHALL использовать скачанные данные при каждом следующем запуске без обращения к сети.

#### Scenario: Второй запуск
- **WHEN** приложение запускается после успешной установки данных
- **THEN** игра стартует сразу, экран «Game data not found» не показывается
