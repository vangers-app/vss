# Spec Delta

## MODIFIED Requirements

### Requirement: Предложение скачать данные
Если при запуске Tauri-сборки (desktop, Android или iOS) данные игры не найдены, экран «Game data not found» SHALL предлагать кнопку скачивания данных рядом со ссылками на Steam и GOG. URL источника задаётся при сборке приложения (см. требование «URL источника задаётся при сборке»); пользователь его не вводит. На мобильных платформах кнопка Exit MUST NOT показываться.

#### Scenario: Первый запуск на iOS
- **WHEN** приложение запущено на iOS и в хранилище приложения нет папки с данными
- **THEN** показан экран «Game data not found» с кнопкой «Download game data», без кнопки Exit

#### Scenario: Первый запуск на Android
- **WHEN** приложение запущено на Android и в хранилище приложения нет папки с данными
- **THEN** показан экран «Game data not found» с кнопкой «Download game data», без кнопки Exit; из ресурсов приложения ничего не распаковывается

#### Scenario: Desktop без Steam-копии
- **WHEN** приложение запущено на Linux/Windows/macOS и ни Steam-путь, ни хранилище приложения не содержат данных
- **THEN** показан тот же экран с кнопкой «Download game data» и кнопкой Exit

#### Scenario: Android после обновления со старой сборки
- **WHEN** приложение обновлено поверх сборки, которая распаковала данные из APK в хранилище приложения
- **THEN** игра стартует с этими данными, экран «Game data not found» не показывается

## ADDED Requirements

### Requirement: URL источника задаётся при сборке
URL архива с данными SHALL передаваться в сборку через переменную окружения `GAME_DATA_URL` и фиксироваться в бинаре на момент сборки. Release-workflow SHALL брать значение из переменной репозитория GitHub `GAME_DATA_URL` для всех платформ. Сборка без переменной MUST проходить успешно.

#### Scenario: Сборка в CI
- **WHEN** в репозитории задана переменная `GAME_DATA_URL` и workflow собирает любую платформу
- **THEN** нажатие «Download game data» в этой сборке скачивает архив по этому URL

#### Scenario: Сборка без URL
- **WHEN** приложение собрано без переменной `GAME_DATA_URL` (локально или в pull request из форка) и пользователь нажимает «Download game data»
- **THEN** показано сообщение об ошибке, что URL данных не задан при сборке, с кнопками Retry и Close; сетевых запросов не выполняется

#### Scenario: Смена URL
- **WHEN** значение переменной репозитория изменено
- **THEN** следующий прогон workflow собирает приложение с новым URL без правок в коде
